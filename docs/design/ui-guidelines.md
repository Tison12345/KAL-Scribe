# Kerala Ayurveda — Brand Guidelines

Colours

Primary: #1E4B3C (deep forest green — used on top bar, buttons, headings)
Secondary: #F2F5ED (light sage — section background tint)
Accent: #AA832A (warm gold — star ratings, decorative accents)
Background: #FFFFFF (white)
Text: #1A1A1A (near-black)

Fonts

Headings: Marcellus (serif — used on h2 and display headings)
Body: Figtree (sans-serif — used for paragraphs, nav, prices, UI elements)

White logo: ../context/ui guidelines/Logos/White Vector.png

minimum size 120px wide, never stretched

## Tone
This is a clinical tool used by doctors in a healthcare setting.
The UI should feel: calm, trustworthy, professional, uncluttered.
NOT: playful, colourful, consumer-app-like.
Think: a well-designed medical records interface, not a wellness app.

## What to avoid
- Bright colours or high contrast decorative elements
- Excessive animations or transitions
- Dense information without breathing room
- Any UI pattern that would feel out of place in a clinic
