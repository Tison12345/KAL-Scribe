# Task Log

Append-only diary. One file per completed task, named
`YYYY-MM-DD-<slug>.md` (e.g. `2026-07-09-recording-flow.md`). Use
`_template.md` as the shape.

Rules:

- **Never edit a past entry.** If something needs correcting, add a new
  entry that references the old one and explains the correction.
- Keep entries short — a few sentences and a bullet list, not a full
  write-up. The detail belongs in `docs/modules/` (if it's a lasting design
  fact) or `docs/adr/` (if it's a decision), not repeated here.
- One entry per task/session, not one entry per file changed.
